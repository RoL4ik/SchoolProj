# 🛠 План розробки проєкту: YT downloader
 
## 1. Концепція продукту
- **Тип додатку:** Веб-Програма
- **Основна ідея:** Завантаження відео з ютуб по посиланню
 
## 2. Основний функціонал (Features)
- [ ] Приймати посилання від користувача
- [ ] Зберегти це відео в історію
- [ ] Завантижити відео
 
## 3. Структура даних
| Назва змінної | Тип даних | Для чого потрібна |
| :--- | :--- | :--- |
| `user_input` | `str` | Ввід посилання |
| `is_right` | `bool` | Перевірка на те, чи є посилання вірним |
